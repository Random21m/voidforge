How to use
  1. Copy this single file to a USB stick and open it on an air-gapped computer.
  2. Press SELF-TEST and confirm it says all tests passed.
  3. Choose Dice or Coin, enter your physical rolls or flips, and press FORGE SEED.
  4. Compare the words and the master fingerprint with a second independent offline tool before trusting real funds.
Method

SHA256(input string) → first 16/20/24/28/32 bytes → BIP39 mnemonic + checksum

The roll or flip string is hashed as plain text. Dice are digits 1–6; coin flips are the characters 1 and 0 (choose which side counts as 1 and keep the exact string). This is the same method SeedSigner uses for its 12/24-word dice and coin-flip modes, and VOIDFORGE reproduces SeedSigner’s published dice examples. Coldcard is documented to use the same dice approach but has not been tested here. The 15/18/21-word lengths are VOIDFORGE’s own extension of the same scheme.

Master fingerprint

PBKDF2-HMAC-SHA512(mnemonic, "mnemonic"+passphrase, 2048) → seed
HMAC-SHA512("Bitcoin seed", seed) → master private key
secp256k1 pubkey → RIPEMD160(SHA256(pubkey)) → first 4 bytes

RIPEMD-160 and secp256k1 are implemented in this file (no libraries). The curve code is not constant-time, which is fine offline but another reason never to run this on a networked or shared computer. The fingerprint includes the optional BIP39 passphrase; the VERIFY box shows it without one.

What SELF-TEST checks

It runs automatically every time the page loads; if any test fails, seed generation is disabled and a red banner appears. Press SELF-TEST to see the full list. It checks: the BIP39 wordlist hash; official BIP39 vectors for 12/15/18/21/24 words; SeedSigner’s published 50- and 99-roll dice examples and 50-roll fingerprint; coin-flip vectors from an independent reference implementation of SeedSigner’s method; the abandon…about fingerprints (with and without the TREZOR passphrase); BIP32 test vector 1; RIPEMD-160 vectors; and the phrase checker. If any test fails, do not use that copy for real funds.

Security notes
  • Only use this offline. Never type a real seed into a phone, website or online tool.
  • The randomness meter checks face counts, long runs, repeating or stepping patterns and periodic repeats. It is advisory only: it catches lazy input, not subtle bias, and cannot prove your dice or coin are good. If it flags a pattern, FORGE SEED asks before continuing.
  • A Content-Security-Policy built into this file tells the browser to block all network access, as a second line of defense. It does not replace using an offline computer.
  • This page contains no links, and switching between dice and coin clears the entered rolls (after asking).
  • The red "appears to be online" banner is a hint from the browser, not proof. A machine can be connected without the browser knowing, so physically disconnect it.
  • Text boxes turn off spellcheck, autofill and autocorrect so the browser doesn’t keep what you type. The passphrase is masked, and is never shown with, copied with, printed with or saved with the words.
  • COPY SEED and PRINT SEED ask for confirmation because the clipboard and print spooler can retain your seed.
  • DOWNLOAD FOR USB saves a clean copy of this page and never includes a generated seed. It is re-serialized by the browser, so its file hash will not match the original; to verify a hash, copy the original file instead. DOWNLOAD (seed) writes your seed and rolls to a plain-text file, so only use it on a trusted offline machine.
  • No independent security audit has been done. Use at your own risk. MIT licensed.
