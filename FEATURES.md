# VOIDFORGE Advanced Features

This version includes:

- All BIP39 lengths: 12, 15, 18, 21, 24 words
- Optional BIP39 passphrase
- Copy buttons for seed and fingerprint
- Entropy quality indicator
- Undo last roll
- Print-friendly view
- Test vector loader
- Dark/light mode
